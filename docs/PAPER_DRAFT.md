# Tracing Semantic State in Code Language Models

## Abstract

Code language models can often produce plausible programs without necessarily tracking the program relations that determine what the code means. Identifier spelling, token proximity, and indentation all correlate with semantic structure, so behavioral success and high probing accuracy can arise from surface cues alone. We study whether pretrained code models internally represent variable binding, def–use structure, control dependence, and taint; how those representations change across layers and under controlled transformations; whether they affect model behavior; and whether they are aligned with the model’s output vocabulary.

We evaluate DeepSeek-Coder models at 1.3B and 6.7B parameters on synthetic Python programs with construction-known program graphs and verified token alignment. Linear probes are evaluated with source-grouped cross-validation, shuffled-label controls, model-free surface baselines, and negative strata designed to remove specific shortcuts. The strongest result concerns variable binding. On context-matched pairs for which the surface baseline and embedding layer are exactly at chance, binding accuracy rises from 0.500 to approximately 0.98–0.99 in the middle layers of both models. Def–use edges show a similar profile and remain accurately decodable across distances of 50–200 tokens. Frozen probes remain robust to inert context and several semantics-preserving rewrites, but degrade sharply under scope shadowing and control-flow flattening. On 200 CodeSearchNet functions, binding and def–use probes reach approximately 0.98 AUC and reproduce the same early-middle-layer peak, although natural identifiers prevent the semantic contribution from being isolated as cleanly as in the synthetic data.

Activation patching provides causal evidence that information associated with a tainted sink argument affects the output. The causal locus moves from the sink-argument token in early layers to the final-token position in late layers, while patching the sanitizer-definition position has no effect. At the same time, decodability does not imply reportability. A validated Jacobian lens recovers next-token content in both code models, but finds no control-dependence signal at layers where a supervised probe reaches AUC 0.999. Finally, after correcting the behavioral task and adding analytic, random-direction, and position-only floors, we find no evidence that probe failure precedes behavioral failure. Together, the results support a model in which code LMs construct and sometimes use program-semantic information, but do not maintain it in a fully invariant or consistently output-aligned form.

## 1. Introduction

Many programming tasks depend on relations that are not visible from a token in isolation. A use of `x` must be linked to the definition that reaches it. A value passed to a sink may or may not have passed through a sanitizer. A statement may be controlled by one guard rather than another at the same indentation depth. A code model that tracks these relations should behave differently from one that relies mainly on spelling, proximity, or common formatting patterns.

Distinguishing these possibilities is difficult because surface form and program semantics are strongly correlated in ordinary code. Two occurrences with the same name often refer to the same variable. Definitions and uses are often close together. Statements inside an `if` block are visibly indented. Natural identifier names such as `result`, `cache`, or `sanitized` also reveal likely roles. A classifier can therefore recover a semantic label without showing that the model has computed the corresponding program relation.

Existing work has shown that pretrained code models encode substantial structural information. Syntax trees can be recovered from intermediate representations, and probes can identify properties related to identifiers, namespaces, data flow, control flow, and data dependence. Work on synthetic programming environments has also shown that next-token models can develop representations of latent execution state. These findings establish that code-model representations contain more than token identity. They leave several questions open, however. It is not always clear whether a probe reads semantic structure or an associated surface cue, whether the decoded information survives controlled changes to the program, whether it is used by the model, or whether it is aligned with what the model can express through its output head.

We address these questions within one experimental pipeline. We generate Python programs with exact binding, def–use, control-dependence, and taint labels; map the corresponding source spans to verified tokenizer positions; and extract hidden states from two frozen DeepSeek-Coder models. We use low-capacity linear probes and evaluate them with grouped cross-validation and shuffled-label selectivity controls. More importantly, we build hard comparisons that remove the shortcut relevant to each task. Context-matched binding pairs hold the visible anchor context fixed while changing the binding relation, forcing both a model-free surface classifier and the context-free embedding layer to chance. Def–use negatives are matched by token distance, and control-dependence negatives occur under a sibling guard at the same indentation depth.

We then ask how stable these readouts are. Frozen probes are applied without retraining to programs containing up to 1,000 tokens of inert or interfering filler and to an execution-verified obfuscation ladder ranging from normalization to control-flow flattening. This separates raw length from semantic interference and distinguishes early name-dependent representations from more structural middle-layer representations. We also evaluate the same probe pipeline on 200 real CodeSearchNet functions.

Finally, we separate representation from use and reportability. Activation patching tests whether replacing a corrupted program’s hidden state with the corresponding clean state changes the model’s answer. A Jacobian lens provides an unsupervised, output-aligned readout of whether an intermediate state disposes the model toward a candidate token. A prefix-by-prefix taint experiment compares probe correctness with the model’s own forced-choice behavior, with explicit floors that prevent unreliable readouts from appearing to provide early warning.

The results support five conclusions. First, binding and def–use information is constructed by the transformer rather than inherited from token identity: controlled binding accuracy rises from exactly 0.500 at the embedding layer to approximately 0.98–0.99 in the middle layers. Second, these representations are robust to distance and inert context but vulnerable to scope interference and flattened control structure. Third, the same decoders transfer to real Python with approximately 0.98 AUC and the same rise-then-decline layer profile. Fourth, activation patching shows that task-relevant information is causally used and moves from the sink argument toward the output position across depth. Fifth, semantic information can be strongly decodable without being output-aligned: control dependence is almost perfectly decoded by a trained probe but remains at chance under a validated Jacobian-lens readout.

These claims are deliberately narrower than saying that the models execute programs symbolically or maintain compiler-like internal data structures. Our experiments show that particular program relations are linearly accessible, robust under some transformations, and in one setting causally consequential. They also expose clear limits. The representations are not invariant to all semantics-preserving rewrites, natural-code experiments do not fully separate lexical and semantic information, and the corrected behavioral experiment provides no evidence of latent failure preceding output failure.

## 2. Related Work

### Structural and semantic probing of code models

Early analyses of pretrained code models concentrated on syntactic structure. Wan et al. studied CodeBERT and GraphCodeBERT using attention analysis, probing, and syntax-tree induction, finding that attention aligns with syntax and that intermediate representations preserve enough information to induce code syntax trees [Wan et al., 2022](https://arxiv.org/abs/2202.06840). AST-Probe extended this line of work by learning a low-dimensional syntactic subspace from which an entire abstract syntax tree could be recovered. Across five pretrained code models, the middle layers contained the most AST information [Hernández López et al., 2022](https://arxiv.org/abs/2206.11719). These studies establish that code-model states preserve grammatical structure and motivate our layerwise analysis. Our focus is different: we study relations such as binding and reaching definitions whose labels cannot, in the strongest controls, be determined from the visible anchor tokens.

Broader diagnostic suites have moved from syntax toward semantics. Troshin and Chirkova introduced probes for syntactic correctness, identifiers, namespaces, data flow, and naming, and examined the effects of model size, code-specific pretraining, and fine-tuning [Troshin and Chirkova, 2022](https://arxiv.org/abs/2202.08975). Ma et al. evaluated seven code models on reconstruction tasks involving ASTs, control-flow graphs, control-dependence graphs, and data-dependence graphs. They found consistently strong syntax encoding but greater variation in semantic structure [Ma et al., 2024](https://arxiv.org/abs/2212.10017). Their DDG and CDG tasks are the closest precedents for our def–use and control-dependence probes. We extend this work by constructing task-specific shortcut controls, freezing probes across controlled distribution shifts, testing causal effects, and distinguishing supervised decodability from output-aligned readout.

Jin and Rinard provide the strongest conceptual precedent for treating program semantics as a latent state. They trained a transformer on programs in a synthetic grid-world language and showed that probes increasingly recover unobserved intermediate execution states during training. Their interventional baseline helps distinguish information contained in the model from computation learned by the probe [Jin and Rinard, 2024](https://arxiv.org/abs/2305.11169). Our study makes a complementary tradeoff. We use pretrained Python models rather than a model trained for a controlled domain, and study static program relations rather than grid-world execution states. Synthetic programs still provide exact counterfactual control, while a CodeSearchNet evaluation tests transfer to natural code.

Related model-design work has injected semantic structure directly. GraphCodeBERT incorporates data-flow nodes, graph-guided attention, edge prediction, and node alignment during pretraining, improving several downstream code tasks [Guo et al., 2021](https://arxiv.org/abs/2009.08366). That result shows the practical value of explicit data flow. We instead ask whether ordinary token-based pretrained models make def–use information accessible without receiving a program graph as input at evaluation time.

### Probe validity and causal evidence

High probe accuracy does not by itself show that a representation encodes the intended property. A sufficiently flexible classifier may learn the task from superficial features or memorize type-level regularities. Hewitt and Liang proposed control tasks and selectivity as a way to place probe accuracy in context: a useful probe should perform well on the target task but poorly when labels are replaced with controls that can only be learned by the probe [Hewitt and Liang, 2019](https://arxiv.org/abs/1909.03368). We follow this principle with linear probes and within-program shuffled-label controls. We also address shortcuts specific to code. Token identity is neutralized by context-matched binding examples, proximity by distance-matched def–use negatives, indentation by sibling-guard controls, and example leakage by grouping all rows from one source program into the same cross-validation fold.

Even a carefully controlled probe establishes availability rather than use. Activation patching, also called causal tracing or interchange intervention, tests whether replacing an internal activation changes a model’s behavior. Its conclusions depend on the corruption and effect metric, so these choices must be explicit [Zhang and Nanda, 2023](https://arxiv.org/abs/2309.16042). Our clean and corrupted programs are token-aligned and differ only in the variable passed to a sink. We measure normalized recovery of the clean-versus-corrupted logit difference and report the potentially direct effect of late last-token patching separately.

### Internal availability and output alignment

The distinction between internal information and behavioral use also appears in long-context language modeling. Lu et al. found that models can encode the location of target information while failing to use it in the final answer, describing this as a “know but don’t tell” failure [Lu et al., 2024](https://arxiv.org/abs/2406.14673). Our context experiment separates inert length from semantic interference, while our taint experiment compares the correctness of an internal readout with the model’s answer. We recover the broad dissociation between an available internal state and an incorrect output, but not the stronger claim that internal failure reliably occurs before behavioral failure.

To study output alignment directly, we use the Jacobian lens introduced by Gurnee et al. The method transforms intermediate activations through a corpus-averaged Jacobian from the current layer to the final residual state, then scores them with the model’s own output head. Unlike a trained task probe, the resulting directions represent a state’s average disposition to affect future output tokens. Gurnee et al. use this construction to identify a verbalizable subspace with properties associated with a global workspace [Gurnee et al., 2026](https://transformer-circuits.pub/2026/workspace/index.html). We first validate the method on code next-token prediction, then use it to ask whether a probe-decodable program relation is also expressed in an output-aligned direction. Because the lens is token-based, our conclusion is restricted to this operational meaning of verbalizability.

The contribution of this work is therefore not the first observation that code models contain syntax or semantic information. It is the joint separation of six questions that are often conflated: whether a relation is recoverable from the surface, whether contextual computation makes it linearly accessible, whether that accessibility survives controlled transformations, whether it transfers to natural code, whether it is causally used, and whether it is aligned with the model’s output vocabulary.

## 3. Experimental Setup

### Models and layer selection

We study DeepSeek-Coder at 1.3B and 6.7B parameters. The 1.3B model has 24 transformer blocks and serves as a smaller-scale replication; the 6.7B model has 32 blocks and provides the main results. All model weights remain frozen. We record the embedding state, denoted layer −1, and a set of layers spaced through the network, including block 0 and the final block. For the 1.3B model these are layers −1, 0, 3, 7, 11, 15, 19, and 23. For the 6.7B model we additionally include layers 27 and 31. Cross-model comparisons emphasize relative depth rather than identical layer numbers.

### Program data and ground truth

The synthetic core dataset contains 740 Python programs covering binding, taint propagation, variable shadowing, and matched control-dependence cases. Binding programs contain definitions, uses, branches, and reassignments. Each identifier occurrence is assigned a binding identity indicating the definition to which it resolves. Taint programs follow a source–propagation–optional-sanitizer–sink pattern and include the live taint state after every relevant line. Shadowing programs deliberately reuse one name for different bindings.

Three additional datasets support controlled evaluation. The context dataset contains 1,200 variants derived from 40 base programs. Five filler types—comment prose, dead code, lexical decoys, competing updates, and scope shadowing—are inserted at sizes from 0 to 1,000 tokens, measured with the model tokenizer. The obfuscation dataset contains 40 base programs at five cumulative levels: normalization, consistent identifier renaming, opaque dead branches, mixed Boolean-arithmetic encoding, and control-flow flattening. Every retained variant is executed to verify observational equivalence, and all levels of a base are retained or rejected together. The causal dataset contains 40 clean/corrupted pairs. The two versions are token-aligned and differ only at the sink argument: the clean program passes a sanitized variable, while the corrupted program passes the raw value.

For natural-code transfer, we use a fixed-seed sample of 200 AST-parseable Python functions from CodeSearchNet. These functions provide a more realistic distribution of identifiers and program structure, although they cannot offer the same surface-controlled counterfactuals as the synthetic data.

Ground truth is derived from the Python AST and the generator’s construction metadata. We recover binding identities, reaching-definition edges, control dependence from lexical nesting and join points, and per-prefix taint state. AST character spans are mapped to tokenizer offsets and checked against the original source. The tokenizer is also required to reconstruct code exactly; this catches configurations that silently split DeepSeek-Coder tokens incorrectly. Def–use extraction is differentially tested against the independent Beniget reaching-definitions analysis. This cross-check previously exposed a real labeling error in a self-referential assignment, illustrating why internal consistency alone is insufficient.

### Probes and controls

All probes are linear logistic classifiers. Pairwise tasks use the hidden states at two relation anchors; single-position tasks use the state at one anchor. We use regularization strength (C=0.1), a maximum of 2,000 iterations, and at most 20,000 samples for each task and layer. Five-fold cross-validation is grouped by source program, ensuring that related rows from the same program never appear in both training and test folds.

We report accuracy, ROC AUC for binary tasks, and selectivity. Selectivity is the difference between target-label accuracy and accuracy obtained when labels are shuffled within each source example. Per-stratum accuracy is used to inspect hard cases, but it is interpreted as class-conditional performance rather than as a replacement for aggregate AUC.

Each relational task includes a shortcut-specific control. For binding, context-matched pairs hold the visible anchor context constant while changing which definition reaches a use. This forces the model-free surface baseline and the context-free embedding layer to exactly 0.500 accuracy. A separate same-name/different-binding stratum tests whether identical spelling actively misleads the classifier. Def–use negatives are matched to positive edges by token distance. Control-dependence negatives are statements under a different sibling guard at the same nesting depth, preventing indentation alone from identifying the relation. A model-free classifier using local token features and distance provides an explicit surface floor.

For the context and obfuscation experiments, probes trained on the core dataset are frozen and applied without retraining. Ground truth is rebuilt for every transformed program. Freezing is essential: retraining in each condition would measure whether a new decoder can learn the condition, not whether the original accessible representation remains stable.

### Behavioral, causal, and output-aligned readouts

The behavioral experiment grows each taint program one line at a time. At each prefix, a frozen probe predicts the live value’s taint state and the model answers the same question through forced-choice `yes`/`no` log probabilities. Thresholds are calibrated on a held-out split. A prompt diagnosis showed that a useful behavioral signal requires both few-shot demonstrations and explicit naming of the current variable. We assess the signal with balanced accuracy and reject lead-time interpretation when it is at chance.

For each readout, we define the first incorrect prefix and compare it with the model’s first incorrect answer. Because a less reliable readout is more likely to fail early by chance, we compare the observed early-warning rate with an analytic null based on its per-prefix error rate. We also include a norm-matched random direction and a position-only classifier that uses no model state.

The causal experiment patches the clean hidden vector into the corrupted run at the sink argument, sanitizer definition, or final token. We report recovery of the clean-versus-corrupted answer-logit difference. A recovery of zero means that patching does not close the behavioral gap; a value of one means complete recovery. Late final-token patches are interpreted cautiously because they can act directly on the output state.

Finally, the Jacobian lens maps an intermediate residual state into output-token directions using the expected Jacobian from that layer to the final layer. We validate the implementation in two ways. At the last layer the Jacobian is the identity, so the Jacobian and logit lenses must agree exactly. We also test whether the lens recovers held-out next-token identifiers better than a logit lens and random directions. Only after these checks do we use it to test taint and control-dependence reportability.

## 4. Results

### Semantic relations are constructed in early layers and retained through the middle of the network

The central result is that variable binding becomes decodable only after contextual computation. On the context-matched binding pairs, both the model-free surface baseline and the embedding layer score exactly 0.500. The relevant information is therefore absent from token identity and the visible anchor features supplied to the baseline. In the 1.3B model, accuracy rises to 0.557 at block 0, 0.962 at layer 3, and 0.981 at layer 7 before declining to 0.915 at the final layer. In the 6.7B model, it rises from 0.528 at block 0 to 0.906 at layer 3 and 0.991 at layer 11, then remains high through the middle of the network and ends at 0.934.

The same-name/different-binding stratum makes this transition especially clear. At the embedding layer, accuracy is approximately 0.001–0.002: because the two occurrences have identical spelling, the classifier confidently favors the wrong relation. By layer 3, accuracy reaches 0.987 in the 1.3B model and 0.967 in the 6.7B model. Contextual processing does not merely add a small improvement over lexical identity; it reverses a strong lexical error. Aggregate binding AUC reaches 0.997 for 1.3B and 0.998 for 6.7B, with selectivity around 0.39–0.40 over 423 source groups.

Def–use edges follow the same general profile. Peak accuracy is 0.989 for 1.3B and 0.990 for 6.7B, with AUC 0.999 in both models. Performance decays only mildly with distance. At layer 3, the 6.7B model scores 0.995 for edges separated by 0–10 tokens, 0.989 for 10–50 tokens, and 0.985 for 50–200 tokens. At the final layer these values are 0.984, 0.982, and 0.962. The 1.3B model shows a similarly small gap. Thus the decoder does not depend only on adjacency, although the final layers preserve less of the relation than the middle layers.

The lexical token-type task provides the expected contrast. It reaches 1.000 accuracy at or near the embedding layer with high selectivity in both models. Token type is already available from the input representation, whereas controlled binding is at chance until transformer blocks add context. Together, these curves suggest a progression from lexical information at the input, to relational information constructed in early blocks and maintained through middle layers, followed by partial reorganization near the output.

Control dependence is also decodable, but the interpretation is less purely semantic. An initial version of the task was invalid because positive statements were uniquely identifiable by indentation and the surface baseline reached 1.000. The rebuilt dataset places hard negatives under sibling guards at the same indentation depth. On this corrected dataset, the model-free baseline still performs strongly: overall accuracy is 0.927 and AUC is 0.990, with 0.959 positive recall and 0.676 recall on indent-matched negatives. Local syntax therefore predicts most of the relation.

Hidden states nevertheless improve both sides of the decision simultaneously. At its best layer, the 1.3B probe reaches 0.981 positive recall and 0.873 hard-negative recall, with AUC 0.997. The 6.7B probe reaches 0.995 and 0.923, respectively, with AUC approximately 0.999. The improvement on hard negatives is about 0.25 for the larger model. This is not simply a threshold tradeoff because positive and negative recall both improve. The appropriate conclusion is that control dependence is represented more clearly after contextual processing, but is also largely reconstructable from local syntax. It is therefore a weaker example of isolated semantic computation than context-matched binding.

Across both model sizes, the four tasks form a consistent hierarchy. Lexical type is available immediately. Binding and def–use relations emerge rapidly and peak in the middle layers. Control dependence shows a similar layerwise improvement, but begins from a much stronger surface baseline. The close agreement between the two model sizes, especially when layers are compared by relative depth, suggests that this organization is not a peculiarity of one checkpoint.

### The representations survive length and ordinary rewriting, but fail under semantic interference

The frozen-probe experiments clarify what these decodable relations depend on. In the context experiment, adding inert text is much less damaging than adding code that interferes with the tracked relation. For 6.7B binding at 500 added tokens, accuracy is 0.921 with prose comments. Dead code and lexical decoys reduce accuracy to 0.794 and 0.795, while competing updates yield 0.859. Scope shadowing is substantially more destructive, reducing accuracy to 0.570. At 1,000 tokens, scope-shadow binding falls to 0.498, indistinguishable from chance, and def–use accuracy falls to approximately 0.59. Other filler types remain above approximately 0.70.

This pattern argues against raw context length as the main cause of degradation. A thousand comment tokens introduce distance without changing scope, and the relation remains readable. Reusing the tracked names in nested scopes forces the model to resolve a genuinely competing binding structure and destroys the frozen decoder. The layerwise pattern supports the same interpretation. Under scope shadowing, block 0 remains relatively stable at about 0.75, while the middle layers that normally contain the strongest binding signal degrade most. The interference affects the contextual computation rather than a simple identifier lookup. Both model sizes show the same ordering of filler types.

The obfuscation experiment reaches a related conclusion using whole-program transformations that preserve observed behavior. For the 6.7B binding probe, layer-averaged accuracy is 0.974 after normalization, 0.726 after consistent renaming, 0.722 after adding opaque branches, 0.738 after arithmetic encoding, and 0.590 after control-flow flattening. Layer averages hide an important distinction. Renaming pushes the embedding and earliest layers below chance, to roughly 0.29–0.33, while middle layers retain approximately 0.85–0.90 accuracy; the best renamed-program result is about 0.897 at layer 11. Early representations are therefore strongly tied to identifier spelling, while middle-layer representations transfer much better to new names.

Opaque predicates and mixed Boolean-arithmetic encoding add little damage beyond renaming. These transformations alter local expressions and add dead branches but usually leave the binding scaffold recognizable. Flattening is different. Once structured control flow is replaced by a dispatch loop, the best binding layer reaches only about 0.75 and the layer average falls to 0.59. The 1.3B model follows almost the same sequence, with binding averages of 0.966, 0.729, 0.707, 0.718, and 0.582 across the five levels.

Taken together, the context and obfuscation results rule out two extreme descriptions. The representation is not a shallow lexical lookup: middle layers survive renaming and large amounts of inert context. It is also not a fully invariant symbolic representation: scope interference and flattened control flow cause severe failure. A more accurate description is a context-sensitive structural representation that tracks relations within familiar scope and control-flow organization.

The real-code evaluation shows that the decoder is not limited to generator templates. On 200 CodeSearchNet functions, 6.7B binding reaches 0.902 accuracy and 0.978 AUC at layer 7, compared with surface AUC 0.673. Def–use reaches 0.911 accuracy and 0.979 AUC at layer 3, compared with surface AUC 0.590. The 1.3B model is nearly identical: binding peaks at AUC 0.980 and def–use at 0.975. In both models, AUC rises from the embedding layer to an early-middle peak and then declines by approximately 0.07 toward the output, reproducing the synthetic layer signature.

Natural code does not isolate semantic information as cleanly as the context-matched synthetic set. Identifier spelling is genuinely informative in CodeSearchNet, so the embedding layer already reaches approximately 0.96 AUC. The real-code result therefore shows transfer of the decoder and its layer profile, not that the transferred performance is independent of lexical cues. The same-name/different-binding stratum also has low negative-class recall, but the result is threshold-dependent and its sample size is not recorded in the current table. It should be treated as a diagnostic limitation rather than as evidence that binding is absent from real-code states.

### Semantic information can affect the output without becoming directly reportable

Activation patching tests whether the information identified by the representational analysis has a causal effect on behavior. In the 6.7B model, patching the clean state into the corrupted run at the sink-argument position produces 0.985 mean recovery at layer 0, 0.912 at layer 3, 0.708 at layer 7, and 0.500 at layer 11. Recovery then falls to 0.235 at layer 15 and approaches zero near the output. The final-token position shows the opposite trajectory: recovery is −0.007 at layer 0, 0.014 at layer 3, 0.074 at layer 7, 0.145 at layer 11, 0.308 at layer 15, 0.650 at layer 19, and 1.000 at layer 31.

The result is a clear movement of causal influence across both layer and position. Early in the network, the identity of the value passed to the sink is locally decisive. Through the middle and later layers, its effect is transferred toward the position used to produce the answer. The smaller model shows the same pattern at compressed depth: sink-argument recovery is 1.087 at layer 0 and 0.872 at layer 3, while final-token recovery rises to 0.899 at layer 19 and 1.000 at layer 23.

Patching the sanitizer-definition position produces 0.000 mean recovery at every measured layer in both models. This does not prove that sanitization is absent from the network. It shows that, under this single-position intervention, the sanitizer-definition state is not a mediator of the measured output difference. The most defensible causal conclusion is therefore local: the sink argument carries output-determining information early, that influence moves to the output position, and the sanitizer-definition position is causally inert in this experiment.

The Jacobian-lens results show that causal use and output-aligned reportability are still different properties. Before interpreting a null result, we verified that the lens works in these code models. At the final layer, where the Jacobian is mathematically the identity, agreement between the Jacobian and logit lenses is exactly 1.0000 for both models. On held-out next-token identifiers, Jacobian-lens top-1 accuracy reaches 0.633 in the 1.3B model and 0.650 in the 6.7B model, compared with chance 0.038 and much lower random-direction floors. Before the final layer, the Jacobian correction improves over the plain logit lens by as much as 0.150 in 1.3B and 0.183 in 6.7B. The readout therefore recovers real code-token content that a direct unembedding misses.

We then apply the lens at guard-expression anchors. A control asks it to rank the variable actually tested by the guard above another variable in the program. In 6.7B this guard-variable score rises from 0.507 at the embedding layer to 0.813 at layer 31, showing that the readout is active and identifier-sensitive at these positions. The control-dependence test instead asks whether the lens ranks the target of the dependent statement above the target of an indent-matched non-dependent statement.

The initial pooled result was near chance through layer 23 and below chance late in the network. Inspection revealed a temporal confound: the dependent target always followed the guard, while some negative targets appeared before it and were already visible under causal attention. Restricting the analysis to cases where the negative also occurs after the guard removes the below-chance tail. On 417 matched comparisons per 6.7B layer, scores range from 0.453 to 0.537 and equal 0.506 at the final layer. Chance lies inside every cluster-bootstrap 95% confidence interval, and no layer is significant after correction for multiple comparisons. One 1.3B layer has a point estimate of 0.576, but its program-clustered interval is [0.495, 0.644] and the effect does not replicate in 6.7B.

This creates the clearest dissociation in the study. A supervised probe reaches approximately 0.999 AUC on control dependence, while a validated output-aligned lens remains at chance on the temporally matched relation. The same lens can identify the guard variable at the same anchors. Under the specific token-ranking operationalization used here, control dependence is decodable but not verbalizable. The conclusion should not be generalized to all forms of reportability: the positive control concerns identifier identity rather than another relation, and the Jacobian lens represents single output tokens more naturally than abstract multi-token concepts.

The taint behavior experiment adds a final distinction between internal correctness and model output. Its first version used a bare question asking whether the current value was tainted. Both models responded constantly: 1.3B always answered `no`, and 6.7B always answered `yes`. Their raw accuracies differed because tainted prefixes were more common, but balanced accuracy was 0.500 in both cases. This constant behavior mechanically created an apparent scale difference in lead time. The smaller model was wrong at the first evaluated tainted prefix, making positive lead impossible, while the larger model first became wrong around sanitized prefixes, allowing any unreliable readout to fail earlier.

A prompt sweep showed that few-shot examples and explicit naming of the current variable were both necessary. With this correction, the 6.7B behavioral signal reaches 0.939 accuracy and 0.836 balanced accuracy over 342 prefixes. The 1.3B signal remains unusable at 0.471 balanced accuracy, so its lead time is undefined rather than zero.

On 6.7B, the corrected analysis provides no evidence of early warning. The no-model position heuristic achieves early-warning excess of +0.113 over its analytic null. Random readouts also produce positive apparent warning in some layers. The trained probe’s mean excess is −0.010 under the reported summary, and isolated positive cells do not support a corrected claim. A broader comparison using Jacobian, logit, probe, and random readouts shows why: across 40 layer/readout combinations, apparent early-warning rate is strongly negatively correlated with the fraction of examples on which the readout is never wrong (Pearson (r=-0.905), (p=1.1\times10^{-15})). Unreliable readouts fail earlier simply because they fail more often.

The absence of early warning does not mean the probe is uninformative. At useful layers its per-prefix error rate is roughly 0.005–0.027, compared with 0.233 for the position baseline. At many layers, it remains correct at every prefix for every example on which the model eventually answers incorrectly. The supported result is therefore not that a latent semantic state degrades before behavior. It is that a highly accurate internal taint readout can remain correct while the model’s forced-choice output is wrong. This observation is consistent with the causal and Jacobian-lens results: semantic information may be present, and some related information may affect computation, without being routed into the requested answer or aligned with a directly reportable token direction.

## 5. Discussion

The experiments converge on a relatively simple account of semantic state in these code models. Lexical information is available immediately. Binding and def–use relations are constructed in the first few transformer blocks, remain strongly linearly accessible through the middle layers, and become less accessible near the output. The same rise-then-decline profile appears in synthetic and real code and at both model scales. This does not demonstrate a symbolic environment or an explicit compiler data structure, but it does show that contextual processing creates a representation that a context-free baseline cannot recover.

The robustness results clarify the level of abstraction. The models tolerate long stretches of irrelevant comments, and middle layers continue to support a binding decoder after all identifiers are renamed. This would be difficult to explain as a direct spelling or proximity heuristic. At the same time, scope shadowing and control-flow flattening cause severe degradation. The representation is therefore tied to recognizable program organization. It abstracts beyond individual names without becoming invariant to every semantics-preserving transformation.

The results also show why representation, use, and reportability must be evaluated separately. The binding and def–use probes establish linear availability. The patching experiment establishes that a hidden state at the sink argument can have a large causal effect on the answer, and that this effect migrates toward the output position. The control-dependence experiment then shows that near-perfect supervised decoding need not correspond to a direction that the model’s own output geometry can express. Finally, the taint experiment shows that an accurate readout can remain correct while the output fails, without providing advance warning of that failure.

One possible interpretation is that the residual stream contains more semantic information than a given output computation uses. A supervised probe can adapt to whatever linear coordinates contain the relation, whereas the output head only accesses directions prepared for the current prediction. The Jacobian lens partially corrects for changing coordinates across layers, yet still finds no control-dependence signal. This suggests that the relation is not merely hidden by a simple rotation into the final basis. It may remain part of an automatic computation rather than a generally reportable state. However, the lens test asks whether the model is disposed to name a single-token dependent target. A different relational output format might produce a different result.

Control dependence itself illustrates the need for calibrated claims. The hidden probe clearly improves over the hard surface baseline, especially on sibling-guard negatives. Yet the surface baseline already reaches AUC 0.990 because control dependence is closely tied to local syntax. The result is meaningful, but it is not as clean as binding, where the controlled surface and embedding floors are exactly chance. More generally, the strength of a probing claim should depend on the strength of the identification strategy, not only on peak accuracy.

The two model sizes agree on nearly every qualitative result: the controlled binding rise, def–use distance robustness, context-filler ordering, obfuscation ladder, causal movement from sink to output position, and control-dependence Jacobian-lens null. The larger model maintains some plateaus across more absolute layers and is the only one able to perform the corrected taint forced-choice task. Two sizes from one architecture family are not enough for a scaling law, but the replication makes it less likely that the central layer profiles arise from a single checkpoint.

## 6. Limitations

The study covers two sizes of one model family. A cross-architecture replication, currently planned with StarCoder2, would be needed to establish broader generality. The synthetic programs are small, single-function Python examples. They provide exact labels and controlled counterfactuals, but omit difficult features such as interprocedural flow, aliasing through objects, exceptions, dynamic dispatch, and concurrency.

Linear decodability is not equivalent to native model use. Although shuffled-label controls and hard strata limit probe learning and surface shortcuts, a frozen probe can fail under transformation because the representation rotates rather than disappears. Conversely, successful decoding does not establish that the relation is used in ordinary generation. The causal experiment addresses use for one taint-related contrast, not for every probed relation.

The real-code evaluation demonstrates transfer but not isolated semantic transfer. Natural identifier identity is highly informative, placing the embedding AUC near 0.96. Context-matched mutations of real functions would provide a stronger test. The existing real-code tables also do not record the size of the same-name/different-binding stratum, limiting interpretation of its low recall.

Activation patching replaces a complete residual vector at one position, so the intervention transports every difference encoded there. It does not isolate a single semantic direction or identify a complete circuit. Late final-token recovery may reflect a direct effect on the output state. The zero sanitizer-definition result is local to the tested position and intervention and does not establish that sanitization is absent elsewhere.

The corrected behavioral result is interpretable only for 6.7B and includes 19 model-wrong examples in the canonical summary. Taint state is correlated with prefix depth in the current generator, which explains why a position-only baseline can appear useful. The trained probe substantially outperforms that baseline on taint classification, but a future corpus should randomize initial taint and include re-taint transitions. Repeating calibration across several seeds would also strengthen the negative lead-time conclusion.

Finally, the Jacobian lens uses small sets of single-token candidates. Its validation shows that it recovers code-token content and improves over a logit lens, but abstract relations may not correspond to one output-token direction. The guard-variable control demonstrates that the readout is active at the tested positions; it is not a relational positive control. We therefore use “verbalizable” only to mean detectable as an output-aligned token disposition under this method.

## 7. Conclusion

Pretrained code models contain more than lexical and formatting regularities. On binding examples where surface features and context-free embeddings are exactly uninformative, both DeepSeek-Coder models build a representation that reaches approximately 0.98–0.99 accuracy in the middle layers. Def–use structure is similarly accessible across substantial token distance, and both relations transfer to real Python with approximately 0.98 AUC.

These representations are structured but not fully invariant. They survive inert length, formatting changes, and several expression-level transformations, while scope shadowing and control-flow flattening expose clear limits. Activation patching shows that information at the sink argument can causally determine the output and moves toward the final position across layers. Yet strong decodability does not guarantee direct reportability: control dependence remains at chance under a validated output-aligned lens where a supervised probe is nearly perfect.

The corrected behavioral experiment reinforces this distinction without supporting early warning. The taint probe can remain correct when the model answers incorrectly, but it does not fail reliably before the model. The overall picture is therefore not of a model that either “understands” or “does not understand” code in a single sense. It is of a model that constructs program-semantic information, preserves it under some conditions, uses selected parts of it, and exposes only a subset through its output computation. Establishing which of these properties holds requires controls and interventions designed for each claim separately.
