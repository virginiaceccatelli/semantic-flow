\begin{abstract}
Code language models can appear competent by exploiting identifier spelling, proximity, and indentation, all of which correlate with program semantics. We ask whether they instead construct program relations, use them, and make them available to their own output computation. Synthetic Python gives us construction-known semantic graphs, exact AST-to-token alignment, and counterfactual pairs whose surface floor is fixed rather than estimated. In DeepSeek-Coder 1.3B and 6.7B, binding accuracy on token-matched pairs rises from exactly 0.500 at both the surface and embedding baselines to approximately 0.984 in middle layers. Activation patching then traces causal recovery from the sink-argument token ($\approx 0.99$ at layer 0) to the final position (1.00 at layer 31); the sanitizer-definition position recovers 0.000 at every layer. Yet this state is dissociated from report and error anticipation. A Jacobian lens validated by exact last-layer identity and next-token recovery reads the guard variable at 0.813, but control dependence remains at chance where a trained probe reaches AUC 0.999. A taint probe is approximately 99\% accurate and remains correct on the prefixes where the model answers incorrectly; no anticipatory degradation survives a no-model floor. Code models therefore build and use program-semantic state without reliably reporting it or using its degradation to anticipate their own failures.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Code language models predict convincing programs, but this does not establish that they compute the relations that determine program meaning. Equal names often denote the same variable, definitions and uses are usually nearby, and indentation exposes control structure. Binding, data flow, and control dependence can therefore be predicted from surface regularities even when the corresponding program relation is not represented.

Code offers an unusually clean way to separate these possibilities. Static analysis provides decidable ground truth, and controlled programs allow counterfactual pairs whose semantic label changes while the relevant surface context is held fixed. This pins a baseline to exactly chance rather than estimating how much a shortcut might explain. We use that leverage to study four properties of semantic state in the same models: whether it is \emph{built} with depth, \emph{used} by the output computation, available for \emph{report}, and \emph{anticipatory} of behavioral failure.

Prior work shows that code-model representations preserve AST structure and expose identifiers, namespaces, data flow, control flow, and data dependence \cite{wan2022capture,hernandez2022astprobe,troshin2022probing,ma2024unveiling}. Controlled language models trained on programs can also acquire latent execution state \cite{jin2024emergent}. These results establish recoverability, but recoverability alone does not distinguish model computation from surface cues or probe learning \cite{hewitt2019control}. Nor does it establish causal use or output accessibility. We connect probing to activation patching \cite{zhang2023patching}, long-context ``know but do not tell'' failures \cite{lu2024longcontext}, and the Jacobian lens for verbalizable representations \cite{gurnee2026workspace}.

Our results give a consistent but non-unitary picture. First, variable binding and def--use structure are absent from controlled input representations and constructed within the first transformer blocks. Second, taint-relevant information causally moves from the sink argument toward the final readout position. Third, control dependence is almost perfectly probe-decodable but absent from a validated output-aligned readout. Fourth, the taint state remains correctly decodable where the model's answer is wrong, rather than degrading beforehand. Program-semantic state is thus built and used, but dissociated from both report and self-prediction.

\section{Setup and Controls}
\label{sec:setup}

We study frozen DeepSeek-Coder models at 6.7B parameters (main) and 1.3B parameters (cross-scale replication). The synthetic Python corpus contains binding, shadowing, control-dependence, and source--propagation--sanitizer--sink programs. The generator records exact semantic graphs; AST spans are mapped to tokenizer offsets and checked against the original source. Def--use ground truth is independently cross-checked against Beniget. Linear probes use five-fold cross-validation grouped by source program and are reported with within-program shuffled-label selectivity.

The experiments are organized around controls that make each claim falsifiable (Table~\ref{tab:controls}). Context-matched binding pairs differ by one binding-changing character while preserving the probe anchors, placing both the model-free surface baseline and context-free embedding layer at exactly 0.500. Def--use negatives are distance-matched, and control-dependence negatives occur under a sibling guard at the same indentation depth. Frozen probes are evaluated under added context and execution-verified obfuscations without retraining. Behavioral and lens nulls are reported only with controls showing that the instrument works at the same decision point.

\section{The Representation Is Built and Causally Used}
\label{sec:built-used}

\paragraph{Built with depth.}
Figure~\ref{fig:binding} gives the strongest evidence that the model computes rather than retrieves a program relation. On context-matched binding pairs, the surface baseline and embedding layer are exactly 0.500 by construction. The first transformer block reaches approximately 0.53--0.57, layer 3 reaches 0.91--0.96, and both models peak near 0.984 in the middle layers. Accuracy remains about 0.92 at the final layer. The curve has three clear phases: no relation at the input, rapid construction in the first blocks, and partial shedding near the output. Def--use edges show the same profile, reaching approximately 0.99 with only mild decay when definition and use are separated by 50--200 tokens.

The stress tests characterize what is built. At 500 inserted tokens, 6.7B binding accuracy is 0.921 under inert comment filler but 0.570 under scope shadowing; at 1,000 tokens, scope shadowing reduces it to chance. Identifier renaming drives the earliest layers below chance while middle layers retain approximately 0.85--0.90. Control-flow flattening is the harder boundary, reducing the best layer to about 0.75. The representation therefore survives distance and surface renaming better than changes that complicate the underlying scope or control structure.

\paragraph{Causally used.}
We next patch hidden states from a clean program, which passes a sanitized value to a sink, into a token-aligned corrupted program that passes the raw value. In 6.7B, recovery at the sink-argument token is approximately 0.99 at layer 0 and declines across depth. Recovery at the final position follows the reverse path and reaches 1.00 at layer 31 (Figure~\ref{fig:patching}). The smaller model replicates the same routing at compressed depth. The relation is locally consequential early and is moved into place for the output late.

\begin{figure}[t]
  \centering
  \includegraphics[width=0.68\linewidth]{patching_recovery_deepseek-coder-6.7b.pdf}
  \caption{Activation-patching recovery in DeepSeek-Coder 6.7B. Causal influence moves from the sink argument in early layers to the final position in late layers. Patching the sanitizer definition recovers 0.000 at every layer.}
  \label{fig:patching}
\end{figure}

The sanitizer-definition position recovers 0.000 at every measured layer in both models. This does not show that sanitization is absent everywhere; it shows that this site does not mediate the answer under the intervention. Section~\ref{sec:correct-wrong} returns to this result from an independent direction.

One relation requires a narrower claim. Control dependence reaches probe AUC 0.999, but its no-model surface baseline is already 0.927. Unlike binding's exact 0.500 floor, much of control dependence is locally reconstructable from syntax. Hidden states improve the relation, especially on same-depth sibling guards, but the result is best treated as a syntactic--semantic boundary and as the foil for the output-accessibility experiment below.

\section{Dissociation I: Built but Not Reported}
\label{sec:not-reported}

A trained probe can recover any linear direction correlated with its labels, including one the model never makes available to its output computation. We therefore use the Jacobian lens to test a stronger property. For a candidate output token $w$ at layer $\ell$, its direction is
\begin{equation}
  v_w = J_\ell^{\top}\bigl(g W_U[w]\bigr),
  \qquad
  J_\ell = \mathbb{E}\!\left[\frac{\partial h_{\mathrm{final}}}{\partial h_\ell}\right],
\end{equation}
where $W_U$ is the unembedding and $g$ is the final normalization factor. The Jacobian is applied through vector--Jacobian products and is never explicitly materialized. Scores are used only for rankings within a position.

Two checks establish that a null is interpretable. At the final layer, $J$ is the identity, so the Jacobian and logit lenses must agree; their measured cosine similarity is 1.0000 in both models. On held-out next-token prediction, the lens reaches top-1 accuracy 0.650 at 6.7B layer 27, compared with at most 0.050 for random directions. Before the final layer it exceeds the logit lens by as much as 0.183. The method therefore recovers code-token content that direct unembedding misses.

At control-dependence guard anchors, the lens ranks two single-token identifiers, with chance exactly 0.500. A same-anchor positive control asks it to identify the variable tested by the guard. This score rises with depth to 0.813 ($z\approx 7.7$), showing that the readout is active and identifier-sensitive at the tested positions. The control-dependence target remains at chance at every layer, including those where the trained probe reaches AUC 0.999 (Figure~\ref{fig:jlens}). The relation is linearly recoverable, but the model is not disposed to name the dependent target.

\begin{figure}[t]
  \centering
  \includegraphics[width=0.72\linewidth]{jlens_controldep_dissociation_deepseek-coder-6.7b.pdf}
  \caption{Probe--report dissociation in DeepSeek-Coder 6.7B. The same-anchor guard-variable control rises to 0.813, while the control-dependence target remains at chance where a trained probe reaches AUC 0.999.}
  \label{fig:jlens}
\end{figure}

The initial pooled analysis fell below chance late in the model because every positive target occurs after its guard, whereas half of the negative targets had already appeared and were visible under causal attention. Restricting negatives to positions after the guard removes this recency artifact. On 415 matched comparisons per layer, 0.500 lies inside every program-clustered 95\% interval after correction over layers. Finding and removing this confound strengthens rather than weakens the null: the late reversal disappears, while the absence of a positive control-dependence signal remains.

The conclusion is deliberately token-level. The guard-variable control establishes that the readout works at these anchors, but it is an identity control rather than a relational one. We therefore show that control dependence is not aligned with a disposition to \emph{name} its target under this readout, not that the relation is inaccessible to every possible output format.

\section{Dissociation II: Correct State, Wrong Answer}
\label{sec:correct-wrong}

If semantic state is built and used, it might seem natural for its degradation to precede a wrong answer. We test this by growing taint programs one line at a time. At every prefix, a frozen probe reads the live value's taint state and the model answers the same question through forced-choice probabilities.

The behavioral signal must first be valid. With few-shot examples and the current variable named explicitly, 6.7B reaches balanced accuracy approximately 0.84. The 1.3B model remains at 0.471, so its lead time is undefined rather than zero. For 6.7B, we compare observed early errors with an analytic null based on each readout's error rate and with a no-model position readout.

The taint probe is approximately 99\% accurate per prefix. At most layers, it is never wrong on any of the 19 examples where the model answers incorrectly: the latent state remains correct at the exact prefixes where behavior fails. No anticipatory degradation survives the floor. Mean probe excess over the analytic expectation is $-0.010$, while the position-only baseline scores $+0.113$. The result is therefore a representation--behavior dissociation, not an early-warning effect.

This converges with the causal result in Section~\ref{sec:built-used}. Patching the sanitizer definition recovers 0.000 at every layer, while the probe correctly reads the sanitized state when the model answers as though it had not. Two independent measurements support the same interpretation: the model represents sanitization but does not route that representation into the requested answer.

An earlier analysis appeared to show advance warning, but the effect came from the metric and the behavioral signal rather than the probe. Under a bare prompt both models were constant responders, and their opposite response biases manufactured an apparent scale difference. More generally, early-warning rate increases with readout error rate ($r\approx-0.96$ within readout families when reliability is measured as the fraction never wrong), so uninformative directions can score highest. This correction is methodologically important, but the substantive result is simpler: the semantic state is accurate when the answer is wrong.

\section{Discussion}
\label{sec:discussion}

The four measurements describe different properties of one semantic representation. Binding and def--use are built from an exact input-level floor. Taint-relevant information is causally routed across depth. Control dependence is probe-decodable but not aligned with a validated verbalizability readout. Taint state remains correct at behavioral failure rather than anticipating it. Computation, causal use, report, and self-monitoring therefore come apart.

This separation matters for interpretability. ``Decodable'' is often treated as the endpoint, but it is only one claim. Evidence for construction requires a surface floor; evidence for use requires an intervention; an informative null requires a positive control at the same readout site; and failure prediction requires comparison with a no-model rule and an error-rate-aware null. These controls are not the subject of the paper, but they determine which statements about the model are justified.

The main limitation is also the reason the synthetic testbed is useful. Real-code probes transfer at approximately 0.90 accuracy and 0.98 AUC, but natural identifiers make the embedding layer highly predictive and prevent an exact semantic floor. Our strongest identification result therefore comes from controlled programs. The study is further limited to Python and two sizes of one model family, and the Jacobian-lens null concerns one token-level operationalization of reportability.

The clearest concrete picture is the sanitizer. Its state is accurately decoded, its definition is causally inert for the answer, and the model can still respond incorrectly. Code models compute semantic state, but computation alone does not guarantee that the right state reaches the answer.
